folio.

Book Rental System · Laravel MVC activity

Your project is ready to install.

Follow these steps once, then use Folio to manage books, borrowers, rentals, and returns. This page is the installation guide; the application runs at the local URL shown by Artisan.

1. Check your tools

You need PHP 8.2 or later within Laravel 12's supported range, Composer 2, and MySQL or MariaDB. XAMPP can provide PHP and the database. Open Command Prompt in the extracted folio-book-rental folder. 

php -v
composer --version

The interface assets are already compiled. Node.js is only needed if you want to rebuild the design.

2. Install the dependencies

composer install
copy .env.example .env
php artisan key:generate
composer check-platform-reqs

Copy .env.example only on a fresh installation. Subsequent copies replace your local settings.

3. Create and connect the database

Start MySQL in XAMPP. In phpMyAdmin, create the database with this SQL: 

CREATE DATABASE folio_book_rental
CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

Set the database connection in .env. Change the port, username, and password to match your computer. 

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=folio_book_rental
DB_USERNAME=root
DB_PASSWORD=

4. Set up and open Folio

php artisan optimize:clear
php artisan migrate --seed
php artisan serve

Open http://127.0.0.1:8000, or the local URL printed by Artisan. Keep the terminal and database server running. The included demo starts with 12 books, 6 fictional borrowers, and 8 rental records.

5. Try the complete workflow

  1. Add a book and a borrower.
  2. Create a rental using that book and borrower.
  3. Open the rental, record its return, and confirm.
  4. Rent the same book again and review its history.

Book availability changes automatically. Records with rental history are retained. Book prices are recorded values; no rental fees or fines are calculated.

6. Prepare for your demonstration

php artisan test

The default tests use an isolated SQLite database and need pdo_sqlite. Functional tests passed on both SQLite and MariaDB, and separate concurrent rent/return checks passed on MariaDB. Visual browser QA was blocked in the build workspace; check your installed app at desktop and mobile widths before presenting.

Everyday startup

After installation, start the database, open a terminal in this folder, run php artisan serve, and visit the displayed URL. You do not need to install or seed again.

Folio is intended for a local classroom demonstration. Do not use database reset commands on records you need to keep. Read the README before making a fresh database reset.
